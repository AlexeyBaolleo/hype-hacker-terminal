# Прототипы дизайна терминала

Это быстрые наброски, чтобы выбрать характер заставки. Все — чёрно-белые,
без внешних зависимостей, работают в любом терминале.

| Файл | Характер |
|------|----------|
| `01-signal.sh` | Техничный, спокойный: 58 тестов с отсылками к фильмам и играм, ползунок до 100%. |
| `02-netrunner.sh` | Cyberpunk 2077 / Watch Dogs: крупный логотип, глитч, `BREACH COMPLETE`. |
| `03-fsociety.sh` | Mr. Robot / whoami: медленный, зловещий набор `ACCESS GRANTED`. |
| `04-ghost.sh` | Watch Dogs / whoami: hex-шум, диалог с машиной, удар `whoami → root`. |
| `05-python.sh` | Анимация перед кодом: случайные приколы, залипание на 99%, затем Python. |
| `06-composite.sh` | **Финальный гибрид:** начало 01 → hex из 04 с инверсным выделением → 58 тестов с отсылками → `we are legion.` → любая клавиша → `clear`. |

## Как смотреть

```bash
./preview.sh 6        # финальный гибрид (жми любую клавишу в конце)
./preview.sh all      # все по очереди
./preview.sh py       # анимация Python-раннера
./preview.sh 3        # только fsociety
```

`PREVIEW=1` оставляет кадр на экране и в конце показывает пример чистого
промпта `$ `. В боевом режиме после нажатия клавиши экран очищается,
и появляется настоящий приглашающий знак оболочки.
