# hype-hacker-terminal

Чёрно-белый fullscreen-терминал: быстрая заставка при открытии, чистый
промпт `$` и отдельная анимация при запуске своего Python-кода.

## Установка

```bash
./install.sh
```

Скрипт работает из любого каталога и сам вычисляет путь к репозиторию.
Он делает три вещи:

- ставит бит исполнимости на скрипты;
- линкует `alacritty.toml` в `~/.config/alacritty/` (чужой конфиг бэкапится);
- добавляет одну строку подключения в `~/.bashrc` (тоже с бэкапом).

Повторный запуск безопасен: старые строки подключения удаляются, симлинк
обновляется. Репозиторий можно клонировать и переименовывать — пути внутри
скриптов считаются от их собственного расположения.

После установки открой новый терминал. Старые окна alacritty нужно
перезапустить.

## Состав

```
alacritty.toml     → ~/.config/alacritty/alacritty.toml  (симлинк)
bash/hacker.sh     → подключается из ~/.bashrc
bin/hacker-boot    → заставка (гибрид: 01 + 04 + 03)
bin/run            → Python-раннер с анимацией
bin/palette.sh     → принудительная ч/б палитра терминала
designs/           → прототипы, из которых собирался финальный вид
install.sh         → установка одной командой
```

## Как это работает

- При открытии терминала: шапка из `01`, hex-дамп с инверсным выделением
  из `04`, 58 тестов с отсылками к Mr. Robot, Cyberpunk 2077, Watch Dogs,
  whoami и Матрице, `we are legion.` из `03`, затем **любая клавиша**
  и только после неё `clear`.
- В `$HOME` промпт — просто `$ ` (для root `# `), в других директориях —
  приглушённый путь и `$ `.
- Подсказки команд отключены (`shopt -u progcomp`); дополнение путей
  через Tab остаётся.
- `run script.py [args...]` — анимация, `clear`, затем настоящий `python3`.
  Команды `python`, `pip`, `uv`, `poetry` не переопределяются.

## Не зависит от темы терминала

Все цвета в заставке заданы явными truecolor-кодами (`38;2;r;g;b`), а не
атрибутами вроде `2m`/`1m`/`7m` и не bright-палитрой `97m`. Поэтому тема kitty
на другой машине не может перекрасить текст и «белый фон — чёрный текст» в hex-дампе.

Кроме того, `bin/palette.sh` выставляет фон `#000000` и текст `#ffffff` прямо
в терминале через OSC 21 (kitty) и OSC 10/11 (остальные эмуляторы). В kitty
перед этим Colors сохраняются в стек (`OSC 30001`), а при выходе из оболочки
восстанавливаются (`OSC 30101`) — чужая тема не ломается навсегда.

Если подключение идёт без bash-профиля (например, сразу в `tmux`), можно
зафиксировать цвета в `~/.config/kitty/kitty.conf` на той машине:

```conf
foreground #ffffff
background #000000
cursor #ffffff
cursor_text_color #000000
```

## Откат

Удали строку подключения `bash/hacker.sh` из `~/.bashrc` (или восстанови
`~/.bashrc.bak.*`) и симлинк `~/.config/alacritty/alacritty.toml`.
